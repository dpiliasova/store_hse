# Аналитический слой интернет-магазина

Исходные данные находятся в PostgreSQL. Загрузчик копирует их в raw базы Greenplum.
В dbt подготовлены слои staging, intermediate и marts.

В marts находятся заказы, позиции заказов и справочники клиентов, товаров и дат.
По ним можно посчитать выручку по месяцам и категориям, средний чек по городам
и долю покупателей по каналам привлечения. Тестовые заказы исключены.

Выручку подтвержденных покупок считаем по order_amount в fct_orders
или по line_amount в fct_order_items при is_confirmed = true.
При соединении заказов с позициями сумма заказа повторяется для каждой позиции.

В исходных данных у заказа 113 стоимость 200 рублей, а успешные списания составляют
400 рублей: две операции по 200. Тест assert_confirmed_orders_not_overpaid
выдает предупреждение. Исходные данные сохранены без исправления этой ошибки.

{% docs confirmed_order %}

Подтвержденная покупка - заказ со статусом paid и хотя бы одной успешной
платежной операцией с суммой больше или равной нулю. Успешная операция
с отрицательной суммой означает возврат и не подтверждает покупку.
Сумма оплаты не обязана совпадать со стоимостью заказа.
